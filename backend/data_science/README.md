# 📊 Data Science Team Module

Welcome to the Data Science Team workspace!

## Your Responsibilities:
1. Place Jupyter notebooks, exploratory data analysis scripts, and Power BI / Plotly export routines here.
2. Query the SQLite/PostgreSQL database at `backend/supplychainx.db`.
3. Plug aggregated operational KPIs and supplier scorecard metrics into: `backend/app/api/v1/analytics_routes.py`.

The REST endpoints at `/api/v1/analytics/kpis` and `/api/v1/analytics/suppliers` power the Analytics Dashboard in the Flutter App!
